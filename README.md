# MarketIQ

Project Description:
This interactive dashboard helps users explore stock market trends and predict future prices. It combines historical stock prices, company financial reports, and economic data like inflation and interest rates into one place. Machine learning models analyze this data to predict whether a stock price is likely to rise or fall next. Users can visually explore interactive charts and test different economic scenarios using simple control sliders. The entire application runs directly inside the web browser, making it fast and easy to use without needing backend servers.
